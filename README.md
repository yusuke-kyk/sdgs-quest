# SDGs QUEST（仮） — ロードマップ＋国家ビュー＋章末報告 Ver.0.3

**20ターンの政策カードゲームのプレイアブル試作**。第42設計判断C案に基づき、Ver.0.1を拡張しています。ビルド・インストール不要です。

## 最短で遊ぶ

- 単体ファイル `sdgs_quest_playable_v03.html` をダウンロードし、ChromeやEdgeで開いてください。
- もしくはZIPを展開して、フォルダ内の `index.html` を開いてください。
- 毎年3枚の候補から1枚だけ実行。20年目終了後に4種のエンディングを表示します。


## Ver.0.3 の追加改善（プレイ感想反映）

- **国家ビューの変化を大幅に強調**：建物・発電施設・樹木を大きく描画。環境負荷39以下なら鮮やかな森と緑地、70以上なら乾燥・霞、85以上なら枯れ木・亀裂・荒廃した都市の表現に切り替える。都市高層化・研究施設も技術上昇で拡大。建設中の発電所も大きく表示。
- **4年分のロードマップ**：前年・今年・翌年・翌々年を1枚のマップに表示。前年の3枚のうち採用カードのみ鮮明に残し、未採用2枚は黒く減光。マップから今年の政策をタップすると、翌年に接続する分野の枠と経路が発光する。
- **カード詳細への導線**：ロードマップで今年のカードを選んだ後、出現する「詳細・実行へ」から既存の政策詳細を開く。年間の政策実行回数は変更なし。
- **旧版セーブ移行**：前年に提示された3枚を保存していなかった旧セーブでは、前年に選んだ1枚のみ履歴から復元し、未採用候補は「記録なし」と表示する。以降は3枚を正確に保存。
- **重要な注意**：来年に表示されるのは「出やすくなる分野」であって、その年に確定する3枚のカードそのものではない。発光は確定カードの予告ではない。

## Ver.0.2の追加機能

**1. 分岐ロードマップ**：政策選択画面に、今の3枚→翌年の分野→その次の分野のマップを追加。現在のノードを押すとカード詳細を開きます。選択したカードの「分野」によって、翌年の抽選の行き先が変化します（政策を選ぶことがルート選択を兼ねるため、年間の追加行動はありません）。

| 今選んだ分野 | 翌年につながる分野 |
|---|---|
| エネルギー | エネルギー・科学技術 |
| 環境保全 | 環境保全・科学技術 |
| 科学技術研究 | 科学技術・エネルギー |
| 施設管理 | エネルギー・環境保全 |

翌年、その2分野に**実行可能な**候補が1枚でもある場合、3枚中**最低1枚**は該当分野から優先して抽選します。残りは従来のランダム抽選・偏り補正です。**来年のカード名・数値・発生イベントは事前確定ではありません**。再来年の点線表示はさらに先の選択の傾向を表すだけで、確約はありません。カード選択に直接のコスト・追加ターンは生じません。

**2. 国家ビュー**：都市・山・川・稼働中の発電施設・環境保全の政策履歴・科学技術値に応じて、簡易2D SVGの国家風景が変化します。国の状態を象徴するイラスト表現であって地理・気象・産業の精密なシミュレーションではありません。追加画像がなくても表示できます。

**3. 5年間の中間報告**：5・10・15年目の結果画面から、5年間の指標変化・分野別政策実行数・イベント履歴・稼働施設数を振り返る「章末報告」へ進みます。20年目は従来どおりエンディングです。報告は確認操作のみで、政策実行枠を使いません。

**4. v0.1セーブから移行**：旧版と同じローカル保存キーを使い、旧版のセーブをバージョン2の構造へ移します。旧版の進捗を残したい場合は、新版を**同一のURL/配信先**で開いてください。ファイル版のセーブ領域はブラウザの仕様によって共有されないことがあります。移行前に別の保存場所に置かれた進捗までは自動的に取り込めません。

## 変更していない基本ルール

- 20年間、年1枚の政策選択、毎年3枚のカード抽選。
- 資源30／環境負荷50／科学技術20で開始。毎年資源+3、基本環境負荷+1。
- 政策カード24種類（政策数値は仮v0.2）。技術制限、施設寿命・管理、研究完成待ち、継続政策と維持費、イベントと一部緊急対応、4つのエンディング。
- 政策画像は `assets/cards/E01.png` のようにカードID別に追加。カード枠・効果数値とは独立。未配置なら絵文字を表示。
- エンディングは環境負荷39以下、科学技術60以上を暫定閾値に4分岐。未完了政策は継承記録。

## フォルダ構成

```
index.html                ブラウザ入口
css/style.css             UIデザイン（v0.2国家ビュー・マップ追加）
js/data.js                カード原本のブラウザ用データ
js/engine.js              ゲーム処理（分岐補正・章末報告追加）
js/app.js                 ブラウザ表示・操作
policy_cards.json         全24枚の原本（仮v0.2）
assets/cards/             文字や数値を焼き込まないカード画像の配置先
tests/smoke.js            20ターン自動テスト
```

## テスト

Node.jsを使用できる場合：

```bash
node tests/smoke.js
```

450回の20ターン自動プレイ、ルートが抽選に作用すること、5年目の章末報告、既存の維持費不足と未完成研究の継承を確認します。ブラウザの表示・クリックも別途テストしてください。

## まだ仮の部分

- ルート接続は分野の二択が中心。実際のSlay the Spireのような固定された未来の個別カード・強敵ノード・ランダム施設などではありません。
- 国家ビューは国の変化を体感するための簡易アート。多様なカードの個別アニメーションや3D建設表現は未対応。
- 中間報告は数値と振り返り文。次章の目標設定などは未対応。
- イベント・技術・環境の因果関係は教育用の抽象化。ゲームバランスの数値はまだ調整用。

**Ver.0.1とは別リポジトリに新規公開するか、既存のSDGs QUESTだけを更新してください。** 他の個人アプリを上書きしないでください。
